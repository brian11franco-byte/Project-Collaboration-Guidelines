# Co-Align | Teacher Project Collaboration & Horizontal Alignment Portal

**Co-Align** is a premium interactive single-page web application designed for teachers at **IPH Schools East Primary X** to plan, sequence, and document cross-curricular project collaborations using the principles of **Horizontal Alignment**.

---

## 🧭 Key Features

* **Interactive Zooming Journey Guide**: A visual, step-by-step flowchart where teachers click on a planning phase (Discover & Map, Sequence & Adjust, Co-design Assessments) to physically zoom in on checklists, tips, and interdisciplinary overlap diagrams.
* **Collaboration Planner**: A split-screen planner for custom projects featuring live inputs and an A4-formatted live preview document.
* **Double-Bordered A4 PDF Printing**: Custom media print stylesheet settings automatically format the preview sheet into a professional curriculum document suitable for administrative submission.
* **Semestral Showcase Blueprints**: Prepopulated with **five real-world templates** from the school's horizontal alignment archives, loadable with one click:
  1. **Body Puppet Intro Project** (Science, English, BI - Grade 1/Primary X, 1st Semester)
  2. **Miniature Stage Drama** (Science, English, BI, RS - Grade 1 Final/Primary X, 1st Semester)
  3. **Water Games Day & Buoyancy** (Science, Math, PE, Music - Grade 1 Final/Primary X, 2nd Semester)
  4. **My Book of Light** (Science, English, Math, Arts - Grade 3 Final/Primary 3, 1st Semester)
  5. **Shopping Center** (Science, Math, English, BI, Chinese, RS, Art - Grade 2 Final/Primary 2, 2nd Semester)
* **Visual Pacing Tracker**: A week-by-week parallel matrix mapping subject alignments.
* **Export Actions**: Quick Copy Markdown table layout and Export JSON backup tools.

## 🚀 How to Run and Use

### Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/brian11franco-byte/Project-Collaboration-Guidelines.git
   ```
2. Open `index.html` in any web browser.

### Deploy to Vercel
1. Go to [Vercel](https://vercel.com).
2. Import this GitHub repository.
3. Click **Deploy**. Vercel will host the app and give you a public URL.
